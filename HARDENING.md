# Hardening: real face identification

This revision addresses `REVIEW.md`: replace isotropic synthetic templates with frozen real AdaFace IR-101 / WebFace12M embeddings from LFW, XQLFW and CPLFW, using identity-disjoint development and hidden banks. Keep the paper's reference training-free transformation and its two encrypted-cost operating points unchanged. Average 16 fixed, paired gallery/basis draws of 1,200 enrolled people and mixed-quality, cross-pose probes. The protocol was chosen for real capture variability and identity coverage, not proximity to paper percentages.

All fixes were selected from `REDTEAM.md`, `REVIEW.md` and the paper before one combined verification job. That job first reproduces the reference, paper sparse baseline, equal-cost simple baseline and random control serially, then runs all changed attacks and better/weaker encoders through the no-argument hidden entry point. Final measured tables and paired identity-cluster uncertainty will be filled in after the job. Earlier synthetic hardening evidence is preserved in `redteam/hardening/PREVIOUS_HARDENING.md`.

Changes beyond the data correction:

- Test bank, partition builder, hidden draw and basis seeds stay only in `eval/test/`. The child encoder cannot read them: a Linux Landlock launcher grants access only to its input/scratch, development bank, code and model assets. It also prevents cross-call state files. It fails closed if restrictions cannot be established. This closes the previous report's explicitly open answer-reading and selective persistent-state attacks.
- A hidden orthogonal basis per draw preserves real cosine geometry while defeating direct vector lookup. The encoder remains an arbitrary per-template procedure, including learned encoders; it is not restricted to reference settings.
- Remove the ten-minute encoder timeout. No scored or reference-path value depends on a wall-clock limit. The backbone is frozen, the draws and seeds are fixed, and everything runs serially.
- Failure in any experiment or draw now produces zero in every scored metric of both experiments, including malformed specs, empty directories and failed quality constraints. Discovery includes every directory and handles name collisions. Nothing reads the train manifest to choose test methods.
- Restore the paper's first-ciphertext accumulator schedule in the real-Paillier check (no unnecessary scalar power or initial-zero addition), use a 2048-bit key, and derive its small input from real development captures. The scored reference transformation itself is unchanged.
- Keep the two experiment weights at 0.5 and all scientific metric coefficients unchanged. Remove differently scaled source-paper numbers from scored result rows; preserve their values unchanged under `_paper_reported`. Actual reference rows are measured on the final real-face setup.
- Refresh the briefing and scoring documents. Archive obsolete builder notes under `notes/history/`. Download commands fetch every source shard and the backbone publicly, with committed SHA256 checks; derived banks are committed for offline evaluation.

Limitations: this is a scaled LFW/XQLFW/CPLFW open-set protocol, not IJB-C or a million-identity HE timing reproduction. Costs count encrypted work per packed SIMD block; test computes exact decrypted code scores and never retrains. It does not establish end-to-end cryptographic security or production latency. Real facial embeddings limit hand-written identity rules; a better integer quantizer is an allowed representation improvement, not label leakage. Copying an honest encoder or adding ignored metadata still requires doing the honest task. Remaining shortcut and headroom findings will be reported with the measured audit below.

Runtime packaging limitation: `README.md` and `manifest.json` are pre-existing `/dev/null` device mounts that cannot be replaced here. They are left untouched. All editable documentation is updated.
